# 🕌 RAK Prayer Pro (2026 Edition) A high-end, responsive web dashboard providing accurate prayer timings specifically for **Ras Al Khaimah, UAE**. Synchronized with official Municipality and Awqaf standards. ### ✨ Key Features * **Official RAK Sync:** Uses the Umm Al-Qura (Method 4) calculation to match UAE ministry times. * **Real-time Countdown:** Dynamic timer showing exactly how much time is left until the next Salah. * **2026 Friday Protocol:** Automatically adjusts Friday Dhuhr times to 12:45 PM per UAE federal decree. * **Dual Calendar:** Simultaneous display of Gregorian and Arabic Hijri dates. * **Glassmorphism UI:** Modern, luxury aesthetic designed for high-end displays and mobile devices. ### 🚀 How to Open 1. **On Laptop:** Simply open the `prayer.html` file in any modern browser. 2. **On Web:** Access via GitHub Pages at `https://[your-username].github.io/[your-repo]/prayer.html` ### 🛠️ Tech Stack * **Tailwind CSS:** For professional styling. * **Aladhan API:** For global timing data. * **JavaScript:** For real-time clock and countdown logic.
